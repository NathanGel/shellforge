# Security policy

## Reporting a vulnerability

Report a security problem privately through GitHub's
[private vulnerability reporting](https://github.com/NathanGel/shellforge/security/advisories/new),
not in a public issue. Include the Shellforge version (**Shellforge › About Shellforge**), your
macOS version, and the steps to reproduce it.

## Supported versions

Only the latest release gets security fixes. **Shellforge › Check for Updates…** installs it.

## iTerm2

Shellforge is built on [iTerm2](https://github.com/gnachman/iTerm2) and merges iTerm2's security
fixes when they are released. A vulnerability that also affects stock iTerm2 should be reported to
the iTerm2 project as well.
