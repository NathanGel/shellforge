# M1c-1 Daemon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Shellforge has its own copy of AiTerm's daemon (`shellforged`): hooks, status and usage work unchanged, the sessions come from the app through a `sessions.update` call instead of iTerm2's Python API, it needs no third-party Python packages at runtime, and it can run beside AiTerm on the same Mac.

**Architecture:** Copy `aiterm/daemon` and `aiterm/hooks` into `Shellforge/daemon` and `Shellforge/hooks`, rename the package `aitermd` → `shellforged`, and give it Shellforge's own support folder, socket, hook port and header names. The daemon reads sessions only through `ItermPort.snapshot()` and `is_connected()`; a new `AppSessions` implements that port from the last list the app sent, and `run` uses it by default, importing iTerm2's bridge only for `--session-source iterm`. Everything else — hook server, router, resolver, status engine, usage, publisher — stays as it is, and so do its tests.

**Tech Stack:** Python 3.11+ standard library at runtime; pytest 9, pytest-asyncio, ruff, mypy for development (in `Shellforge/daemon/.venv`). The app side of `sessions.update` is M1c-2.

**Spec:** Shellforge PRD (Claude Doc 89fd80a8-5fcf-4423-a8d6-c62f8512a481): "Architecture" (keep `aitermd` for hooks, status, usage; the Python API bridge disappears), Decisions ("keep the Python daemon for v1"), W6 (status from the existing hook receiver, unchanged). Research notes from this session: hooks find their tab by `ITERM_SESSION_ID` (`X-AiTerm-iTerm-Session` header) or, for Claude, by the job pid in `~/.claude/sessions/<pid>.json`.

## Global Constraints

- Source: AiTerm at `~/aiterm` (GPLv3, copyright Laurens D'Hondt). Copied files keep their content; `Shellforge/daemon/NOTICE.md` names the origin and licence. Nothing in `~/aiterm` is modified.
- Shellforge's identity, used everywhere the copy said AiTerm:
  - support folder `~/Library/Application Support/Shellforge/`
  - socket `shellforged.sock`, info file `daemon.json`, log `shellforged.log`, `hook-port`, `statusline-original.cmd` in that folder
  - hook port **47831** (AiTerm uses 47821)

  - session tags `shellforge_task` / `shellforge_project` / `shellforge_title` (matching `ShellforgeTags` in the Swift package)
- At runtime the daemon imports only the standard library unless started with `--session-source iterm`.
- Tests run with `Shellforge/daemon/.venv/bin/pytest -q` from `Shellforge/daemon`; ruff and mypy as configured in its `pyproject.toml`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Nothing is pushed without asking.

## Review Focus

1. **AiTerm running beside Shellforge**: both daemons start, each on its own socket and port, and a hook posted to one never reaches the other. (Task 2 test: defaults; Task 4 check.)
2. **A hook that arrives before the app's first `sessions.update`**: it waits one re-tick as today, and is placed once the session list arrives, not dropped. (Task 3 test.)
3. **A tab the app stops listing** (closed): the daemon forgets it on the next update, and its status events say closed. (Task 3 test.)
4. **A malformed `sessions.update`** (missing field, wrong type): answered `bad_params`, and the previous list stays. (Task 3 test.)
5. **The `iterm2` package absent**: `python -m shellforged run` starts and serves without it. (Task 3 test.)

- [ ] **Step 3: Write `AppSessions`**

`Shellforge/daemon/shellforged/app_sessions.py`:

```python
"""Sessions as the Shellforge app reports them. Shellforge owns its tabs in-process, so the daemon
does not ask iTerm2 for them: the app sends the list (`sessions.update`) and this port hands the
last one to the registry on each tick, as the iTerm2 bridge's snapshot did."""
from __future__ import annotations

from collections.abc import Awaitable, Callable
from typing import Any

from .models import PROJECT_TAG, TASK_TAG, RawSession
from .protocol import RpcError


class AppOwnsWindows(RuntimeError):
    """Windows and tabs are the app's to make; the daemon only tracks what it is told."""


def parse_sessions(params: Any) -> list[RawSession]:
    """The `sessions.update` params as RawSessions, or RpcError('bad_params') naming the first fault."""
    if not isinstance(params, dict) or not isinstance(params.get("sessions"), list):
        raise RpcError("bad_params", "sessions.update needs {sessions: [...]}")
    parsed: list[RawSession] = []
    for i, s in enumerate(params["sessions"]):
        def need(key: str, kind: type | tuple[type, ...], optional: bool = False) -> Any:
            value = s.get(key) if isinstance(s, dict) else None
            if value is None and optional:
                return None
            if not isinstance(value, kind) or isinstance(value, bool) and kind is int:
                raise RpcError("bad_params", f"sessions[{i}].{key} is missing or not {getattr(kind, '__name__', kind)}")
            return value
        tags = {tag: value for tag, value in ((TASK_TAG, need("taskId", str, True)), (PROJECT_TAG, need("projectId", str, True)))
                if value is not None}
        parsed.append(RawSession(session_id=need("sessionId", str), window_id=need("windowId", str),
                                 tab_index=need("tabIndex", int), command_line=need("commandLine", str, True),
                                 job_pid=need("jobPid", int, True), title=need("title", str), cwd=need("cwd", str),
                                 user_vars=tags, active=need("active", bool)))
    return parsed


class AppSessions:
    def __init__(self) -> None:
        self._sessions: list[RawSession] = []

    def replace(self, sessions: list[RawSession]) -> None:
        self._sessions = list(sessions)

    async def connect(self) -> str:
        return "Shellforge"

    def is_connected(self) -> bool:
        return True

    async def close(self) -> None:
        return None

    async def snapshot(self) -> list[RawSession]:
        return list(self._sessions)

    async def session_info(self, session_id: str) -> RawSession | None:
        return next((s for s in self._sessions if s.session_id == session_id), None)

    def _refuse(self, *_: Any, **__: Any) -> Any:
        raise AppOwnsWindows("Shellforge makes its own windows and tabs")

    create_window = create_tab = activate_window = set_frame = close_window = _refuse
    send_text = set_session_tags = set_session_titles = set_aiterm_background = _refuse

    def on_new_session(self, cb: Callable[[str], Awaitable[None]]) -> None:
        return None

    def on_session_closed(self, cb: Callable[[str], Awaitable[None]]) -> None:
        return None

    def on_window_activated(self, cb: Callable[[str], Awaitable[None]]) -> None:
        return None

    def on_disconnect(self, cb: Callable[[], Awaitable[None]]) -> None:
        return None
```

The `_refuse` aliases are async-callable from the window manager only if they are coroutines; make `_refuse` `async def` so `await iterm.create_window(...)` raises `AppOwnsWindows` rather than `TypeError`. Adjust the method names to whatever `ItermPort` declares if Task 2's renames touched `set_aiterm_background`.

        """The app's tabs, replacing the last list; answered after the tick that reads them."""
        from .app_sessions import AppSessions, parse_sessions

            raise RpcError("bad_params", "sessions.update needs the app session source")
        self.iterm.replace(sessions)
        await self.tick()
        return {"ok": True}
