# M12d The sheets — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Shellforge's sheets read as macOS 26 sheets: system-shaped text fields, buttons on the sheet itself, compact one-field sheets, and one keyboard rule everywhere.

**Spec:** `Shellforge/docs/plans/2026-10-14-m12-modern-ui-design.md` (step 4).

## Found already native (no change)

Sheets are real `beginSheet` sheets; the primary button is `.borderedProminent` (⌘↩), the secondary the system bordered button; pop-ups are `NSPopUpButton` at `.large`; toggles are system checkboxes; Remove Task / Project and Delete Branch are `NSAlert`s.

## Before and after (recorded here; the user waived per-step sign-off)

| | Before | After |
| --- | --- | --- |
| Text fields (`Input`, `SearchField`, prompt editor) | House box: 6 pt corners, window-background fill | macOS 26 field: 8 pt continuous corners, the system text background (`Palette.fieldFill`); the house focus ring kept |
| Footer | Raised grey band under a rule | The buttons on the sheet itself, no band, no rule |
| Rename, New Terminal, Add Divider (`NameSheet`) | Fixed 560 pt tall for one field | Sized to its content |
| Agent hooks | Plain ↩ presses Done; ⎋ does nothing | ⌘↩ presses Done, ⎋ closes, as every other sheet |

## Ruling

Converting the multi-step sheets (New Task, New Review, Backpack, Tunnels) to System Settings–style grouped `Form`s is not done here: their dropdowns' layering, keyboard rules and dozens of geometry and key tests are built on the current layout, for little visual gain. The grouped form is Settings' (M12e). Cost if wrong: these sheets keep their own section layout.
