# Contributing to Shellforge

Shellforge takes **change requests**, not pull requests.

## Asking for a change

Open an issue on [GitHub](https://github.com/NathanGel/shellforge/issues/new/choose) and pick:

- **Change request:** something Shellforge should do, or do differently. Say what you are trying to
  get done and what gets in the way, rather than only the fix you have in mind.
- **Bug report:** something Shellforge does wrong. Give the steps, what you expected, what happened,
  and the version from **Shellforge › About Shellforge**.

Each request is read, and either planned into a version, answered, or closed with the reason.
What ships is listed in [CHANGELOG.md](CHANGELOG.md).

## Pull requests

Shellforge does not accept pull requests, so they are closed without review. If you have written
a change, describe it in a change request instead; a link to your branch is welcome as
background. Thank you for understanding.

## Problems in iTerm2 itself

Shellforge keeps iTerm2's terminal as it is. A problem that also happens in stock
[iTerm2](https://iterm2.com) belongs with the iTerm2 project; anything Shellforge adds — the
sidebar, tasks, agents, tunnels, Backpack Mode, updates — belongs here.

## Security

Report a security problem privately through GitHub's
[private vulnerability reporting](https://github.com/NathanGel/shellforge/security/advisories/new),
not in a public issue.
